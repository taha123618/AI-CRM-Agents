# Database Development Skill

Use this skill when modifying database schemas, updating or creating SQLAlchemy ORM models, running migrations, or managing connection pools.

## 🚀 Guidelines

1. **Defining SQLAlchemy Models**:
   - Models belong in `database/models.py`.
   - Inherit from `Base = declarative_base()`.
   - Use `UUID(as_uuid=True)` for primary keys with a default of `uuid.uuid4`.
   - Always define explicit `CheckConstraint` blocks where logical bounds apply (e.g., scores must be 0-100).
   - Use indexes (`db.Index` or `index=True` on columns) for columns that are queried frequently (e.g. `email` on contacts).

2. **Managing Relationships**:
   - Explicitly define `relationship()` and link tables via `ForeignKey`.
   - Always use `back_populates` instead of `backref` for model relationship matching.

3. **Running Database Migrations**:
   - Ensure the database server is running.
   - Run autogenerated Alembic revisions:
     ```bash
     alembic revision --autogenerate -m "description_of_changes"
     ```
   - Apply changes to the database:
     ```bash
     alembic upgrade head
     ```
   - For local quick setup/resets (no Alembic migrations), run:
     ```bash
     python -c "from database.models import Base; from database.connection import engine; Base.metadata.create_all(bind=engine)"
     ```

## 📋 Example Model Structure

```python
from sqlalchemy import Column, String, ForeignKey, Integer, CheckConstraint
from sqlalchemy.dialects.postgresql import UUID
from database.models import Base
import uuid

class Project(Base):
    __tablename__ = 'projects'

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    company_id = Column(UUID(as_uuid=True), ForeignKey('companies.id'), nullable=False)
    name = Column(String(255), nullable=False)
    priority = Column(Integer, default=5)

    __table_args__ = (
        CheckConstraint('priority >= 1 AND priority <= 10', name='check_priority_range'),
    )
```
